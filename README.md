# rustub
RUST Simple Tiny Understanding Blockchain

A minimal, educational blockchain implementation in Rust.  
No magic, no frameworks — just clear code to understand how blockchains work under the hood.
🎯 Why?

    Learn by reading: Every component is small and documented.
    Visualize the process: See mining, validation, and peer communication in real-time logs.
    Experiment on the fly: Change difficulty, inspect mempool, query chain state while the node runs.
    Extend easily: Add signatures, P2P sync, or HTTP API without rewriting core logic.

🚀 Quick Start

cargo run

echo "TX:Alice:Bob:42" | nc localhost 3000
